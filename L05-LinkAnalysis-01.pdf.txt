1.2 Dijkstra algorithm
Find shortest path from source node s to the other 
nodes of graph
d(v): Distance from node s to node v
S1: Initialize d(s) = 0; d(v) = ꝏ
S2: Arrange the nodes in a specific order in a queue Q
S3: Get node u from queue Q then update distance d(v) (if needed) 
of every node v adjacent to node u
Go back to step S2 until every node is computed

Formula
27
R(A) = (1 – d)  / N + d * ΣB:(B,A) ∈E R(B) / do(B)
R(A): Thứ hạng của đỉnh A
d: damping factor
N: số đỉnh của đồ thị
(B,A) cạnh của đồ thị
do(B) bậc ra của đỉnh B

Algorithm PageRank(d, E)
1.
Init page ranks R(0);
2.
i = 1;
3.
repeat
4.
for each page A do
5.
R(i)(A) = (1 – d)  / N + d * ΣB:(B,A) ∈E R(i-1)(B) / do(B);
6.
endfor
7.
i++;
8.
until converged
